## Comparison

All three fail. T0 and T2 failed the same way at the same point: after the opening listings, their first extraction script printed snippets for every hit file across the store with no cap (149M and 69M characters) and the run ended on context overflow before any review or answer. T1's first scan timed out with only an error line, so it survived, moved to background scans writing to files, path greps, screening reads and in-matter snippet scripts, and opened every qualifying matter; it failed at the write stage by excluding the matter whose only executed document is an amendment and by describing the LP-side review matter as the reviewed vehicle's own matter. Its reviews pushed toward a stricter executed-only set and told it not to reclassify matters, so they did not catch the exclusion. Label notes were ignored throughout; the one followed note came after a harness stage-check notice.
