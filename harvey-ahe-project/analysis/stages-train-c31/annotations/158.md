## Comparison

The three runs followed the same arc: store listings (all printed 530-700K characters of file paths), path searches or store-wide scans for processing-agreement words, then reads of the same group of candidates. Every run included matters whose processing agreements are exhibits or addenda to commercial agreements, backed only by closing letters or a closing memo, one of which has a placeholder closing date. Reviews named these weak supports in every run, and each agent re-read the closing papers and kept the matters.

The runs differ on the privacy-program matter whose vendor rider is the executed agreement. T0 read the rider (and the matter's blank template) in an agent-defined reading stage, re-read it twice after reviews said 25 lines were not enough, and still excluded it as unsigned. T1's path search listed the rider, but it opened only that matter's data-sharing agreement and dismissed the matter as template work. T2's scan and inventory showed the matter, and it never opened it.

T0 used seven agent-defined stages (listing, reading, verification and post-write screening). T1 and T2 used fewer, and theirs were signature-check and reading stages. None of them changed the set of included matters.

Label checks: start notes were ignored five times (a store-wide path search under a store-listing label in T0, two request-keyword path searches under a document-type label in T1, first candidate reads under an in-depth label and a multi-matter snippet scan under an in-matter label in T2). End notes were ignored twice (T0 kept the store-listing label for listing named matters; T1 kept the document-type label for its next path search). The rest had no later work of that kind.
