# Taxonomy changelog (round 4)

- **start**: taxonomy copied from round 3 (stages-train-c30).
- **round 4 merge** (batches 1-10, 80 tasks, 240 runs):
  - **Promoted stage: "Tabulate candidate matters from saved results".** Rule: group agent-defined (and declared) spans by what their calls do; promote if the group occurs in >=2 runs, at least one all-passing, and no existing stage describes it. Group: calls that only work on scratch files saved by earlier steps (per-matter hit counts, rankings, tables, filters/unions of hit lists, printing saved hits, coverage checks against the matter-folder list, hand-written per-matter tables of findings already read), with no new text extraction, document reads or file listing. Evidence after relabelling: 142 spans in 100 runs of 65 tasks, 26 of those runs all-pass (e.g. 034_T1 [28]-[33], 032_T0 [54]-[61], 111_T0 [22]-[29], 056_T0 [97]-[102], 210_T1 [40]-[43]). No existing stage fits: "Scan document text with an extraction script" is defined as a script that unzips and searches store documents, and these calls read no document; "Calculate figures for the answer" computes deliverable figures from values already read, while these steps choose candidates; listing and file-name stages touch the store. Batch 2's "NEW: Tally saved search output per matter" and batch 3's "NEW: Tabulate findings across candidate matters" are merged into it; batches 1, 7 and 10 had coded the same work as Scan or Calculate.
  - **Relabelled to the new stage (142 spans):** 112 from "Scan document text with an extraction script", 14 from NEW Tally, 4 from "Search file names for request keywords" (printing, summarising or merging saved name-hit lists), 4 from "Search within a candidate matter's files", 2 from "List files in candidate matters" (printing saved hit paths; a coverage check of saved candidate sets), 1 each from "List matter folders" (coverage check of saved hits), "Calculate figures for the answer" (052_T2 [153]-[160] scratch table), NEW Tabulate, NEW Write a working notes file, and 2 from NEW Rank candidate matters without tool calls. Spans the agent had declared under another label got `declared: <label> (attempt N).` at the start of the note; agent-defined spans keep `declared: new: <name>`. Two moved from a listing label to the new stage had their hindsight reset from the result markers (068_T2 [108]-[115], 192_T0 [54]-[59]: target surfaced). Error records on relabelled stages were renamed (047_T1, 149_T2, 181_T0, 211_T1); no error moved.
  - **Mixed spans** (saved-output processing plus a walk of matter folders for file names or a file-type count) are labelled by the main output and tagged `mixed intents`: per-matter table -> new stage (26 spans, e.g. 032_T0 [62]-[71], 149_T2 [48]-[53], 206_T1 [57]-[62]); printed file lists -> "List files in candidate matters" (057_T2 [44]-[49], was NEW Tally; hindsight target opened); store-wide path ranking -> "Search file names for request keywords" (057_T1 [30]-[35], was NEW Tally). Scan-labelled spans whose main output is a candidate file inventory were left as annotated (e.g. 137_T2 [58]-[65]). Spans that poll a running background scan stay "Scan document text with an extraction script". Name-pattern matching over a saved full-store file inventory stays a file-name search, per-folder counts from it stay "List matter folders", and files of named matters from it stay "List files in candidate matters".
  - **Other NEW names (single-run) mapped:** "Rank candidate matters without tool calls" (247_T0 [60]-[63], [64]-[67]; agent "Tally matters and rank by recency"; no tool call, the summary ranks candidates already read) and "Write a working notes file" (072_T0 [85]-[90]; a per-matter audit table written to a scratch file) both fit the new stage and were relabelled to it. No `NEW:` names remain.
  - **Label fields:** every stage carries `label_check` (the "Check the label" note at stage_start) and `label_check_end` (the end-of-stage "Label: these calls looked like 'X'" note). Batch 3 (048 056 058 121 151 194 198 210) used one field; it was split from the logs: start note only -> value kept in `label_check`; end note only -> moved to `label_check_end`; both notes -> `label_check` recomputed (ignored when the span did the suggested stage's work under the declared label, followed when the agent closed an empty span and opened the suggested stage), and `label_check_end` taken from the batch value when it differed from that, else from the note text or the next stage doing X's work. 048_T2's `followed` on stage 3 was moved to stage 2's end note. md rows of these tasks show `_Label check: …_` / `_End label check: …_`.
  - **Error kinds:** unchanged. 066 (all three runs) codes "opened a required proof document but left it out of the cited documents" as `missing-detail` (hindsight `answer misses document`). Not split into a new kind: it occurs in one task only (three runs of one rubric criterion), and missing-detail already covers omitting what the read documents state. Revisit if another task shows it.
  - **Conventions:** `agent_new` keeps the agent's exact wording (it may contain task words); notes mask task words. md rows touched by the merge were regenerated from the JSON. check.py over all 80 tasks: ALL CHECKS PASSED.
