## Comparison

All three runs failed the same way, on precision at the write stage (over-inclusion): each found and cited the needed matter and the second permitted one, but also asserted a matter about an inquiry into promotion of an already approved drug, and T1 and T2 added matters whose documents merely mention an existing authorization. Discovery differed (file-name searches, store-wide scans that timed out, hand-picked shortlists), but every run reached the same candidates. No review questioned the shared extra matter; reviews pushed for wider coverage and for keeping the matter set, and only T2's review asked whether one extra matter's authorization was material, which the agent re-read and kept. Label notes were ignored on screening stages declared as listing reads (T0) or in-depth reads (T2).
