# Taxonomy changelog

- **start**: empty taxonomy; built from campaign 23 C0 training runs only.
- **batch 1** (tasks 003 028 032 034 061 066 072): first vocabulary. Stages (13): List files in the document store; List matter folders; Search file contents for request keywords; Scan document text with an extraction script; Search file names for request keywords; List files in candidate matters; Read documents picked from the file listing; Screen candidate matters by reading documents; Read a chosen matter's documents in depth; Search within a candidate matter's files; Write the response; Check or revise the response; Finish the run. Tags (9): listing covers few matters, no matches, timed out, huge output, file not found, tool error, script error, mixed intents, run ended: context overflow. Hindsight values (12 new): target surfaced, target partly surfaced, target in folder list only, target missed, target opened, decoy opened, answer passes, answer misses target, answer wrong matter, answer over-inclusive, answer hedged, context overflow. Error kinds (5): search-miss, partial-listing-as-corpus, context-overflow, over-inclusion, hedged-answer. Added stage-range convention and an Issues section.
- **batch 2** (tasks 082 104 111 167 176 206 221, all-pass 056 201): no new stages or tags; all 27 runs fit the batch-1 stage vocabulary. Error kinds (2 new): surfaced-not-opened (needed matter in the agent's own results but never opened; 104_T0, 167_T1, 167_T2, 206_T1), missing-identifier (right matter read but its number never stated; 221_T2). Hindsight values (1 new): answer lacks matter number. Issues added on over-inclusion after in-depth reads, mixed omission + over-inclusion answers, hindsight on surfaced-not-opened stages, multi-matter snippet scripts, provisional writes, and empty greps with non-recursive globs.
- **merge** (batches 3-13 `NEW:` names folded in; all 80 tasks; `check.py` ALL CHECKS PASSED, 213/213 failing runs with first_error, no `NEW:` left). **Accepted** (≥2 runs or a first error): stages *Calculate figures for the answer* (5 runs), *Search file names for a document type* (now 7 runs); tags *run ended: text reply without finish* (4), *output capped* (10), *binary output* (4); hindsight *answer misses document* (3), *answer misdescribes matter* (on 058_T1's first-error stage); error kinds *under-inclusion*, *misstated-facts*, *listed-document-not-opened*, *miscount*, *incomplete-population*, *over-narrow-filter*, *mistyped-path*, and *answer-not-written* (1 later error; kept as the one exception because no existing kind fits without a false cause). **Merged**: over-exclusion, misjudged-exclusion, opened-but-excluded, opened-then-excluded, dismissed-after-shallow-read, under-inclusion and the exclusion uses of misread-matter (047_T1, 053_T0, 053_T1, 057_T2) → under-inclusion; wrong-detail, misstated-facts, misattributed-matter, misattributed-document, misclassification and the misdescription uses of misread-matter (052_T0, 052_T2, 058_T0-T2) → misstated-facts; comparators-listed-as-qualifying → over-inclusion; run ended: no finish call / answer given as chat text → run ended: text reply without finish; own line cap reached → output capped; binary noise → binary output; answer lacks proof document → answer misses document. **Rejected as separate names**: misread-matter (split as above), dismissed-after-shallow-read, comparators-listed-as-qualifying, misclassification, wrong-detail, misattributed-matter, misattributed-document, over-exclusion, misjudged-exclusion, opened-but-excluded, opened-then-excluded. **Remapped for consistency**: 063_T1 hedged-answer → under-inclusion;
