## Comparison

All three runs failed, each with a different first error but the same overall pattern: incomplete coverage of the seven needed matters plus over-inclusion of asset-purchase deals whose leases were assigned. T0 surfaced all seven by file name but never listed one (surfaced-not-opened) and excluded two it read as lender-consent comparators, one of which the review had itself suggested was a lender-consent hit. T1 surfaced all seven but scanned only a hardcoded candidate list that dropped three (over-narrow-filter). T2 viewed its scans only through truncated or candidate-filtered output and never saw two (search-miss). Reviews flagged these only generically; in T2 the reviews also pushed to drop a needed portfolio matter, which the agent kept as borderline.
